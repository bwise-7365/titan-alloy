# SWIFT Core Libraries

This project contains third-party JAR references used by the SWIFT2020 project.
This repository is intended to be cloned into the SWIFT2020 project directory.

This project is not a git sub-project or sub-module.

# Setup

1. Clone SWIFT2020 project into NetBeansProjects directory.
2. Navigate into SWIFT2020 project root directory.
3. Clone this project into the project root.  This should create a new directory
called "lib" that includes the dependent JARs.

Other SWIFT2020-dependent projects will refer to these JARs in the SWIFT project
location if they need to use them.
