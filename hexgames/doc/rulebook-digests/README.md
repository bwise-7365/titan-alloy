# Rulebook digests

These are the per-game digests behind [`../wargame-rulebook-outline.md`](../wargame-rulebook-outline.md), written 2026-10-07. Each one follows the same template:

- 0, rulebook structure;
- 1, situation and design;
- 2, map;
- 3, units;
- 4, movement;
- 5, combat;
- 6, supply;
- 7, other systems;
- 8, observations for a rulebook-outline writer.

Notes on reading the digests:

- **Text files.** A "Source files read" line that names a `.txt` file (e.g. `pgg.txt`, `trc-ref.txt`) refers to a `pdftotext -layout` extract of the PDF named beside it. The extracts were working files and are not kept.
- **Values from images.** Several charts exist only on the map or on aid cards. Where a digest gives values read from a map image, it says so, and those values may contain reading errors from low-resolution images.
- **Estimated counts.** Unit counts are estimates unless the digest cites a rule that states them.
- **Paraphrase.** The digests paraphrase the rules and do not reproduce them.
