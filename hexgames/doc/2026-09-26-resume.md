## Build gotcha (cost an evening)
A CMake configure run without the MSVC environment writes every `CMAKE_CXX_FLAGS*` cache entry EMPTY (no
`/EHsc`), and later configures keep them: throw paths then hang or crash (GridTest, SessionTest). CMakeLists.txt
now refuses such a cache. Configure only through `tools\build-dev.cmd` (loads vcvars64, uses CLion's CMake 4.3.1).
