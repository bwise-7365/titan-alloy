## Gotchas learned this week

- The Bash tool mangles backslashes in heredocs: multi-line C++/XML edits go through a scratch Python
  script that does exact-string replacement (never in the repo), or the Write tool.
- The image viewer drops images when a request carries too many pixels: at most six ~1000 px JPEGs
  per request; a dropped image says "media removed" -- never write a reading for one you did not see.
- A golden that passes on first try deserves a look: the VL golden passed vacuously because the
  reference SVG was rendered from a sheet HexMapEd had stripped. Check the reference has the feature.
- HexMapEd's writer emits only what SheetDoc holds: any new XSD attribute needs a SheetDoc field, a
  parse line, a writer line, and a round-trip test, or the editor's save loses it.
