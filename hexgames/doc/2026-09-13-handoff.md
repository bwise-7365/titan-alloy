## 4. Decisions and conventions to keep (details in PLAN.md)

- No graph library (OGDF is GPL; CXXGraph the fallback). ABC coordinates re-implemented in
  `hexcoord`; `panj\hexmap` untouched; one algebra, orientation in the pixel mapping. Printed hex ids
  are the identity everywhere; offset (col,row) exists only at the grid boundary.
- Prompt/submit players; mid-resolution choices are `PendingDecision`s, never blocking calls.
- Every XSD change is a review gate for Ben (XML Copy Editor). Pending his review: `hexsave.xsd`,
  `hexpackage.xsd` (incl. `<side>`). Proposals parked: `unit-type/@reveal`, `phase/@repeat-per-side`,
  `phase/@caps`, `panel/@space`.
- Engine conventions a game overrides: empty hostility matrix = everyone is an enemy; default
  supply only marks `isolatedP`; `DefaultPhaseGate` guesses caps from phase names; the combat
  decision is a single round trip until the CombatPlan fix lands (M6 obligation).
- Style: `#pragma once`, PascalCase files, 2-space `.clang-format`, Allman definitions, braces on
  every `if`, Yoda literals, trailing-`P` predicates, `throw std::invalid_argument` (never assert,
  never a silent default), exhaustive `switch` without `default`, insertion-ordered containers on
  any path to a PRNG, three-line copyright banner top and bottom of every C++ file, the copyright
  line first and last in every md/txt/py/cmake/ps1/puml file.
- Goldens are never hand-edited: `hexgames_cli --record`, review by `git diff`.
